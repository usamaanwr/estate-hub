# 🏠 EstateHub

A full-stack real estate platform connecting buyers, sellers, and agents — built with **Next.js**, **Node.js/Express**, and **PostgreSQL**.

> Project is currently under development

---

##  Tech Stack

- **Frontend** — Next.js 14, Tailwind CSS
- **Backend** — Node.js, Express.js
- **Database** — PostgreSQL, Prisma ORM
- **Auth** — JWT (Access + Refresh Tokens)
- **File Upload** — Cloudinary

---

##  Roles & Access

| Role | Access |
|------|--------|
| Admin | Full platform control |
| Agent | Manage listings, handle bookings |
| Seller | Add/edit own properties |
| Buyer | Browse listings, book visits |
